# Отчёт по разделу 4.2: Системы передачи в основной полосе частот

## 1. Введение и основные понятия

Особое внимание уделено **двоичным системам передачи в основной полосе частот** — системам, в которых используются сигналы с двумя уровнями. В последующих разделах будет показано, что двоичные системы энергетически более эффективны, а спектрально менее эффективны, чем многоуровневые М-ичные системы.

### 1.1. Спектральная эффективность

**Спектральная эффективность** (другой термин — эффективность использования полосы частот) может быть выражена удельной скоростью передачи, т.е. количеством переданных битов в секунду на один герц:

$$\eta = \frac{R_b}{B} \quad \left[\frac{\text{бит}}{\text{с} \cdot \text{Гц}}\right]$$

Эта нормированная величина является важным параметром системы.

**Пример:** если данные передаются со скоростью 1 Мбит/с в системе с основной полосой частот, равной 0,6 МГц, то спектральная эффективность составит:

$$\eta = \frac{1 \text{ Мбит/с}}{0,6 \text{ МГц}} = 1,67 \text{ бит/(с·Гц)}$$

### 1.2. Эквивалентная низкочастотная модель

Исследование, анализ и реализация фильтров систем с когерентными цифровыми модемами часто проводятся на более простой эквивалентной модели в основной полосе частот (низкочастотном эквиваленте).

#### Основные функциональные блоки:

| Блок | Обозначение | Функция |
|------|-------------|---------|
| Фильтр нижних частот | ФНЧ | Предмодуляционная / послемодуляционная фильтрация |
| Полосовой фильтр | ПФ | Устранение внеполосных шумов и помех |
| Схема восстановления несущей | СВН (CR) | Формирование чистой немодулированной несущей |
| Схема восстановления тактовой частоты | СВТЧ (STR) | Формирование символьной синхронизации |
| Одноразрядный АЦП | А/Ц | Пороговый компаратор |

#### Типы фильтрации:

- **Предмодуляционная фильтрация** — когда ФНЧ при передаче сигнала в основной полосе существенно ограничивает спектр сигнала источника двоичных сообщений $a(t)$.
- **Послемодуляционная фильтрация** — когда ограничение полосы частот при передаче сигнала осуществляется полосовым фильтром (ПФ).

#### Модель канала

Для имитации шумов системы используется модель **линейного широкополосного канала**. Очень часто преобладающей составляющей шумов являются шумы радиочастотного (РЧ) усилителя приемника. Если шумовая полоса значительно шире (например, в 10 раз) полосы модулированной несущей, то спектральная плотность шума считается равномерной, а шум — «белым». В этом случае плотность распределения вероятности шума приближается к теоретической гауссовской плотности. В этом случае мы имеем модель **аддитивного белого гауссовского шума (АБГШ)**.

#### Важное соотношение для символьной скорости

В двоичных системах передачи термин **символ** является синонимом биту, символьная скорость $f_s$ эквивалентна битовой скорости $f_b$, т.е. $f_s = f_b$ только для двоичной передачи; в других случаях символ может содержать несколько битов.

В системах QPSK:

$$f_s = \frac{f_b}{2}, \quad T_s = 2T_b$$

это означает, что один символ содержит два бита информации.

## 2. Спектральная плотность цифровых сигналов в основной полосе частот

Рассматриваются двоичные сигналы различной формы:

- **БВН** — без возвращения к нулю (Nonreturn to zero, NRZ)
- **ВН** — с возвращением к нулю (Return to zero, RZ)
- **MSK** — манипуляция с минимальным частотным сдвигом

Во всех случаях предполагается, что это случайные сигналы синхронных систем; т.е. пересечения нулевого уровня происходят в точках, кратных целому числу тактовых интервалов, равных длительности символа $nT_s$, где $n = 0, 1, 2, 3, \ldots$, а $T_s$ — длительность символа.

### 2.1. Общее выражение для спектральной плотности

Окончательное выражение для спектральной плотности $W_s(f)$ можно представить в следующем виде:

$$W_s(f) = W_u(f) + W_v(f)$$

$$W_s(f) = 2f_s p(1-p)|G_1(f) - G_2(f)|^2 + f_s^2 [pG_1(0) + (1-p)G_2(0)]^2 \delta(f) + 2f_s^2 \sum_{m=1}^{\infty} |pG_1(mf_s) + (1-p)G_2(mf_s)|^2 \delta(f - mf_s)$$

где использованы следующие обозначения:

| Обозначение | Описание |
|-------------|----------|
| $W_s(f)$ | Полная спектральная плотность мощности (включая непрерывные и дискретные компоненты спектра) двоичных синхронных цифровых сигналов |
| $W_u(f)$ | Непрерывная часть спектральной плотности мощности |
| $W_v(f)$ | Дискретная часть спектра, которая может включать и постоянную составляющую |
| $G_1(f)$ | Преобразование Фурье сигнала $g_1(t)$ |
| $G_2(f)$ | Преобразование Фурье сигнала $g_2(t)$ |
| $m$ | Целое число ($m = 1, 2, 3, \ldots$) |
| $p$ | Вероятность появления сигнала $g_1(t)$ |
| $1-p$ | Вероятность появления сигнала $g_2(t)$ |

### 2.2. Пример 4.2.1 — Спектральная плотность сигнала БВН

**Условие:** вывести выражение для спектральной плотности мощности синхронного двоичного цифрового сигнала БВН. Считать, что вероятности появлений логических состояний 0 и 1 равны, а постоянная составляющая отсутствует.

**Решение:**

Для симметричных состояний $+A$ или $-A$ сигнала БВН имеем:

$$g_1(t) = \begin{cases} +A, & -\frac{T_s}{2} \leq t \leq \frac{T_s}{2} \\ 0, & \text{вне этих пределов} \end{cases}$$

$$g_2(t) = \begin{cases} -A, & -\frac{T_s}{2} \leq t \leq \frac{T_s}{2} \\ 0, & \text{вне этих пределов} \end{cases}$$

$$p = 1 - p = 0,5$$

Преобразование Фурье сигнала $g_1(t)$:

$$G_1(f) = \int_{-T_s/2}^{T_s/2} A e^{-j2\pi ft} dt = \frac{A}{\pi f} \sin(\pi f T_s)$$

Аналогично:

$$G_2(f) = \int_{-T_s/2}^{T_s/2} (-A) e^{-j2\pi ft} dt = -\frac{A}{\pi f} \sin(\pi f T_s)$$

Так как $G_1(f) = -G_2(f)$, то $G_1(f=0) = -G_2(f=0)$. Для частот, кратных частоте следования символов ($f = mf_s$):

$$G_1(f = mf_s) = \frac{A}{\pi m f_s} \sin(\pi m f_s T_s) = \frac{A}{\pi m} \sin(\pi m) = 0$$

Аналогично:

$$G_2(f = mf_s) = 0$$

Подставив выражения в общее уравнение, получим:

$$W_s(f) = 2f_s p(1-p) \left|\frac{2A \sin(\pi f T_s)}{\pi f}\right|^2 + 0 + 0$$

Полная спектральная плотность равновероятного ($p(+A) = p(-A) = 0,5$) случайного симметричного цифрового сигнала БВН равна:

$$\boxed{W_s(f) = 2A^2 T_s \left(\frac{\sin(\pi f T_s)}{\pi f T_s}\right)^2}$$

**Важные свойства полученного спектра:**

1. Отсутствуют постоянная составляющая и гармоники.
2. Первый нуль спектра имеет место на частоте $f = 1/T_s = f_s$, т.е. на частоте следования символов.
3. И хотя постоянная составляющая равна нулю, спектральная плотность имеет **максимальное значение** $2A^2 T_s$ при $f = 0$.

> ⚠️ **Важно:** необходимо уловить разницу между отсутствием постоянной составляющей сигнала и максимальной спектральной плотностью на нулевой частоте.

### 2.3. Пример 4.2.2 — Практический расчёт

**Условие:** рассчитать спектральную плотность мощности случайного равновероятного сигнала БВН с частотой следования символов $f_s = 100$ кбит/с. Логическое состояние 1 представлено напряжением $+100$ мВ, а логическое состояние 0 — напряжением $-100$ мВ. Напряжения измерены на нагрузке 75 Ом.

**Решение:**

В формуле (4.2.10) сопротивление принято равным 1 Ом. Для системы с сопротивлением 75 Ом, работающей со скоростью 100 кбит/с ($T_s = 1/f_s = 10^{-5}$ с), спектральная плотность, Вт/Гц, определяется выражением:

$$W_s(f) = \frac{2(0,1)^2}{75} \cdot 10^{-5} \left(\frac{\sin(\pi f \cdot 10^{-5})}{\pi f \cdot 10^{-5}}\right)^2 \approx 2,66 \cdot 10^{-9} \left(\frac{\sin(\pi f \cdot 10^{-5})}{\pi f \cdot 10^{-5}}\right)^2$$

Спектральная плотность мощности на частоте $f = 0$ Гц:

$$W_s(f=0) = 2,66 \cdot 10^{-9} \text{ Вт/Гц}$$

Выражая эту величину в децибелах относительно 1 мВт на герц:

$$W_s(f=0) = 10 \lg(2,66 \cdot 10^{-9}) \text{ дБВт/Гц} = 10 \lg(2,66 \cdot 10^{-6}) \text{ дБм/Гц} = -55,76 \text{ дБм/Гц} = -85,76 \text{ дБВт/Гц}$$

**Практические замечания:**

- Максимальное значение спектральной плотности в пределах первого бокового лепестка на **13,5 дБ** ниже максимального значения спектральной плотности в пределах основного лепестка.
- Если сигнал измерен анализатором спектра с шумовой полосой 3 кГц, то измеренное значение будет на $10 \lg(3000/1) = 35$ дБ выше вычисленного значения спектральной плотности.

### 2.4. Спектральные особенности различных форматов

| Формат | Первый нуль спектра | Дискретные составляющие |
|--------|---------------------|-------------------------|
| БВН (без пост. сост.) | $f_s$ | Отсутствуют |
| ВН | $2f_s$ | Присутствуют |
| MSK | $1,5 f_s$ | Присутствуют (из-за несимметрии) |

Основной лепесток сигнала MSK на **50% шире** основного лепестка сигнала БВН при одинаковой частоте следования импульсов.

## 3. Основы передачи сигналов по каналу с ограниченной полосой и «глазковые» диаграммы

### 3.1. Идеальный канал с прямоугольной частотной характеристикой

Система цифровой передачи с ограниченной полосой будет более эффективно использовать полосу, если она может передавать большее количество битов за секунду в заданной полосе. Полоса часто нормируется к 1 Гц, так что спектральная эффективность может быть выражена в [бит/(с·Гц)].

В своей основополагающей работе по характеристикам канала в 1928 г. Найквист сформулировал требования к минимальной ширине полосы канала для синхронных потоков импульсов сигнальных форматов БВН и других видов. Он доказал, что можно обеспечить передачу деформированного, ограниченного по полосе сигнала и прием с восстановлением идеальной формы.

#### Параметры идеального канала

Частота среза, известная также как **частота Найквиста**:

$$f_N = \frac{1}{2T_s} = \frac{f_s}{2}$$

где $T_s$ — длительность символа, а $f_s$ — частота следования символов (символьная скорость).

В многоуровневых (многопозиционных) системах:

$$T_s = T_b \log_2 M$$

где $M$ — число уровней сигнала.

#### Импульсная характеристика канала

Импульсная характеристика канала $h(t)$ определяется обратным преобразованием Фурье частотной характеристики $H(f)$:

$$H(f) = \begin{cases} 1, & |f| \leq f_N \\ 0, & |f| > f_N \end{cases}$$

$$h(t) = \int_{-\infty}^{\infty} H(f) e^{j2\pi ft} df = \frac{\sin(2\pi f_N t)}{2\pi f_N t} = \frac{\sin(\pi t / T_s)}{\pi t / T_s}$$

Предполагается, что фильтр имеет линейную фазовую характеристику. Фаза $\theta(f)$ равна 0 на всех частотах.

Из выражения для импульсной характеристики следует, что:

- $h(t)$ имеет **максимальное значение** при $t = nT_s = 0$
- $h(t)$ **переходит через 0** при всех других значениях $t$, кратных длительности символа

Если канал с идеальной прямоугольной частотной характеристикой имеет ненулевую, но линейную фазовую характеристику, то импульсная характеристика сдвигается во времени на величину, равную задержке канала. Эта задержка равна $\tau = d\theta/d\omega$ и для фильтров с линейной фазовой характеристикой постоянна для всех частот. Так как импульсная характеристика сохраняется такой же, как и при $\tau = 0$, то дополнительные искажения не вносятся.

### 3.2. Свойства импульсной характеристики

**Ключевое наблюдение:** если сигнал на входе канала (сигнал возбуждения фильтра) — дельта-функция $\delta(t)$ — имеет бесконечно короткую длительность, то выходной сигнал (импульсная характеристика, или импульсный отклик) имеет бесконечно большую длительность. Ограничение полосы канала расширяет импульсную характеристику за пределы интервала $T_s$ и искажает передаваемый сигнал.

**Полезное свойство:** импульсная характеристика принимает нулевые значения в моменты времени, кратные $T_s$.

Следовательно, в канале с прямоугольной частотной характеристикой и полосой $f_N = 1/(2T_s)$ можно передавать и восстанавливать синхронные случайные последовательности импульсов с частотой следования:

$$f_s = \frac{1}{T_s} = 2f_N$$

Теоретически восстановление любого из импульсов может быть выполнено без каких-либо помех со стороны ранее или позднее переданных импульсов. Эта ситуация известна как **передача без межсимвольных искажений (МСИ)**.

### 3.3. Глазковые диаграммы

Для оценки ухудшения качества канала и сигнала часто используются **глазковые диаграммы** или глазковые структуры.

#### Методика наблюдения

Их можно наблюдать на осциллографе, если сигнал типа $v_o(t)$ подать на вход «Y» его вертикального усилителя. Сигнал символьной синхронизации $c(t - nT_s)$ подается на вход внешней синхронизации осциллографа. Регулировкой задержки запуска синхронизации можно расположить глазковую диаграмму в середине экрана. Период горизонтальной развертки устанавливается приблизительно равным длительности символа. Благодаря присущему электронно-лучевым трубкам свойству послесвечения воспроизводятся наложенные сегменты сигнала $v_o(t)$.

#### Практический пример: фильтр Баттерворта 4-го порядка

На рис. 4.2.7 показана полученная экспериментальным путем глазковая диаграмма сигнала на выходе обычного фильтра Баттерворта 4-го порядка без коррекции фазы.

**Параметры эксперимента:**
- Символьная скорость источника ПСП: $f_s = 1$ Мсимв/с = 1 МБод
- Частота среза фильтра по уровню 3 дБ: 550 кГц

**Результат:** вследствие межсимвольных искажений (МСИ) канала без коррекции фазы глазок в точке отсчета открыт приблизительно на **85%** (вместо 100%).

Для поддержания равного запаса при решении, т.е. для получения той же $P_e$, что и в случае отсутствия межсимвольных искажений, уровень сигнала должен быть увеличен на:

$$\Delta L = 20 \lg\left(\frac{1}{0,85}\right) = 1,4 \text{ дБ}$$

Для разработчика системы такое ухудшение вследствие межсимвольных искажений может создать серьезную проблему.

### 3.4. Дрожание (джиттер) переходов данных

На глазковой диаграмме можно заметить, что многократно наложенный сигнал пересекает горизонтальную нулевую линию в точках, не соответствующих точно целому кратному длительности символа.

**Пиковое дрожание (джиттер) переходов данных** ($J_{pp}$) — отклонение от номинальных точек пересечения.

Это дрожание оказывает влияние на работу схем восстановления символьной частоты и может значительно ухудшить характеристики последовательно соединенных секций регенерации.

## 4. Теоремы передачи Найквиста и спектральная эффективность

### 4.1. Теорема Найквиста о минимальной полосе канала

**Формулировка:** если синхронные короткие импульсы с частотой следования $f_s$ символов в секунду подаются в канал, имеющий идеальную прямоугольную частотную характеристику с частотой среза $f_N = f_s/2$ Гц, то отклики на эти импульсы можно наблюдать независимо, т.е. без межсимвольных искажений.

#### Обобщение на многоуровневые системы

При передаче без межсимвольных искажений можно не ограничивать амплитуду импульсов только двумя значениями (например, $\pm S(t)$). Передача без межсимвольных искажений может осуществляться также, если синхронный цифровой поток имеет вид:

$$\sum_k A_k \delta(t - kT_s)$$

где $A_k$ — многоуровневая дискретная случайная переменная.

Например, $A_k$ может принимать одно из следующих значений: $-3, -1, +1$ или $+3$. В этом случае мы имеем **4-уровневую систему передачи в основной полосе частот**, в которой каждый переданный символ сформирован из двух битов данных.

Многоуровневые системы типа 4-уровневых систем в основной полосе частот известны также как системы с **амплитудно-импульсной манипуляцией — АИМ** (Pulse Amplitude Modulation, PAM).

#### Необходимость амплитудного корректора для прямоугольных импульсов

Для короткого импульса амплитудный спектр равномерен на всех частотах, в то время как для прямоугольных импульсов он имеет вид $(\sin x)/x$. Для сохранения одинаковой характеристики системы (т.е. отсутствие межсимвольных искажений как при импульсном возбуждении, так и при прямоугольных импульсах) необходимо, чтобы преобразование Фурье в обоих случаях было идентичным.

Преобразование Фурье на выходе получается умножением преобразования Фурье возбуждающего сигнала на передаточную функцию канала. В случае передачи прямоугольных импульсов передаточная функция канала с прямоугольной характеристикой модифицируется **амплитудным корректором вида $x/\sin x$**.

Тогда можно получить передачу без межсимвольных искажений с эффективной скоростью **2 симв/(с·Гц)**.

#### Практические ограничения идеального канала

Описанные каналы Найквиста с минимальной полосой **не реализуемы**:

1. Для синтеза канала с прямоугольной частотной характеристикой и бесконечным затуханием за пределами полосы пропускания потребовалось бы **бесконечное число звеньев фильтра**.
2. Спад боковых лепестков импульсной характеристики оказывается очень медленным. Это, в свою очередь, привело бы к недопустимо большим межсимвольным искажениям (т.е. $P_e$ может приблизиться к 0,5) из-за малейших неточностей при фильтрации или при символьной синхронизации.

Чтобы обойти эти проблемы и определить более реальные характеристики канала, Найквист сформулировал **теорему о частичной симметрии**.

### 4.2. Теорема Найквиста о частичной симметрии: фильтры с характеристикой приподнятого косинуса

**Формулировка:** суммирование действительной кососимметричной функции передачи с характеристикой передачи идеального фильтра НЧ сохраняет моменты пересечения импульсной характеристики с нулевой осью. Эти пересечения с нулевой осью обеспечивают необходимое условие передачи без межсимвольных искажений.

#### Условие симметрии

Свойство симметрии $Y(\omega)$ относительно частоты среза $\omega_N$ (угловая частота Найквиста $\omega_N = 2\pi f_N$) фильтра с прямоугольной частотной характеристикой и линейной фазой определяется выражением:

$$\boxed{Y(\omega_N - x) = -Y(\omega_N + x), \quad 0 < x < \omega_N}$$

где $\omega_N = 2\pi f_N$.

Результирующая амплитудно-частотная характеристика симметрична относительно частоты Найквиста $f_N$. Эта частично-симметричная амплитудно-частотная характеристика вместе с линейной фазо-частотной характеристикой обеспечивает передачу без межсимвольных искажений.

### 4.3. Фильтр с характеристикой приподнятого косинуса

Одной из часто используемых функций, удовлетворяющих теореме частичной симметрии, является функция **приподнятого косинуса** (косинус на пьедестале).

#### Амплитудно-частотная характеристика

$$H(\omega) = \begin{cases} 1, & 0 \leq \omega < \frac{\pi}{T_s}(1 - \alpha) \\ \frac{1}{2}\left[1 + \cos\left(\frac{T_s}{2\alpha}\left(\omega - \frac{\pi(1-\alpha)}{T_s}\right)\right)\right], & \frac{\pi(1-\alpha)}{T_s} \leq \omega \leq \frac{\pi(1+\alpha)}{T_s} \\ 0, & \omega > \frac{\pi(1+\alpha)}{T_s} \end{cases}$$

где $\omega = 2\pi f$ и $\alpha$ — канальный коэффициент скругления.

#### Альтернативная форма записи

$$|H(f)| = \begin{cases} 1, & 0 \leq f < f_N - f_x \\ \frac{1}{2}\left[1 + \cos\left(\frac{\pi(f - f_N + f_x)}{2f_x}\right)\right], & f_N - f_x \leq f < f_N + f_x \\ 0, & f > f_N + f_x \end{cases}$$

$$\varphi(f) = \text{const}$$

где $\alpha = f_x / f_N$ — коэффициент скругления.

#### Характеристики канала для передачи прямоугольных импульсов БВН

В реальных системах, используемых для передачи синхронных прямоугольных импульсов со скоростью $f_s = 1/T_s = 2f_N$, к характеристикам канала, описанным выражением выше, необходимо добавить характеристику амплитудного корректора вида $x/\sin x$. Тогда необходимая для передачи импульсов (типа сигналов БВН) без межсимвольных искажений характеристика канала определяется выражением:

$$H(\omega) = \frac{\cos\left(\frac{\alpha T_s \omega}{2}\right)}{\sin(\omega T_s / 2)} \cdot \frac{\pi}{4\alpha}$$

при $\frac{\pi(1-\alpha)}{T_s} < \omega < \frac{\pi(1+\alpha)}{T_s}$, и $H(\omega) = 0$ при $\omega > \frac{\pi(1+\alpha)}{T_s}$.

#### Влияние коэффициента скругления $\alpha$

| Значение $\alpha$ | Полоса пропускания | Примечание |
|-------------------|---------------------|------------|
| $\alpha = 0$ | $f_N = 1/(2T_s)$ | Нереализуемый фильтр с минимальной шириной полосы |
| $\alpha = 0,5$ | Расширение на 50% | Компромиссное решение |
| $\alpha = 1,0$ | В 2 раза больше минимальной теоретической | Максимальное скругление |

Теоретически на частоте $f = (1+\alpha)f_s$ затухание фильтра бесконечно большое. В практических ситуациях задается затухание от 20 до 50 дБ, в зависимости от допустимого уровня помех от соседнего канала.

#### Фильтр «корень квадратный из приподнятого косинуса»

Корень квадратный из величины в выражении выше известен как фильтр с характеристикой **«корень квадратный из приподнятого косинуса с коэффициентом скругления $\alpha$»**. Сокращение: фильтр $\sqrt{\alpha}$ или $\sqrt{RC}$.

В приемнике такой фильтр используется в качестве **согласованного фильтра Найквиста**.

### 4.4. Пример 4.2.3 — Расчёт частоты затухания 30 дБ

**Условие:** определить частоту, на которой затухание канала с теоретической характеристикой приподнятого косинуса равно 30 дБ. Скорость передачи данных БВН $f_s = 1$ Мбит/с, коэффициенты $\alpha$ фильтра равны 0,3 и 0,5.

**Решение:**

Частота Найквиста идеального фильтра с прямоугольной частотной характеристикой:

$$f_N = \frac{f_s}{2} = 500 \text{ кГц}$$

Точка с затуханием 30 дБ находится на частоте чуть ниже, чем частота точки с бесконечным затуханием. В первом приближении будем считать, что эти частоты равны.

- В случае $\alpha = 0,3$: нужное затухание достигается на частоте $(1 + 0,3) \cdot 500 \text{ кГц} = 650 \text{ кГц}$
- В случае $\alpha = 0,5$: на частоте $(1 + 0,5) \cdot 500 \text{ кГц} = 750 \text{ кГц}$

### 4.5. Влияние коэффициента скругления на дрожание

На глазковых диаграммах для синхронных последовательностей данных БВН, прошедших через канальные фильтры с характеристикой приподнятого косинуса, с учетом апертурных корректоров вида $x/\sin x$:

| Коэффициент $\alpha$ | Дрожание $J_{pp}$ | МСИ | Спектральная эффективность |
|----------------------|-------------------|-----|---------------------------|
| $\alpha = 0,3$ | 36% от $T_s$ | 0 | Высокая |
| $\alpha = 1,0$ | 0% | 0 | Низкая |

**Вывод:** спектральная эффективность обратно пропорциональна коэффициенту $\alpha$.

## 5. Формирование сигналов QPSK, MSK, GMSK и FQPSK в основной полосе частот

### 5.1. Исторический контекст

К 90-м годам большинство американских, японских и европейских комитетов по стандартизации сотовой/беспроводной связи одобрили относительно простые и помехоустойчивые виды модуляции:

| Стандарт | Регион | Вид модуляции |
|----------|--------|---------------|
| Североамериканские и японские цифровые сотовые системы | США, Япония | Модификация QPSK ($\pi/4$-DQPSK) |
| Европейские и международные применения | Европа (GSM) | MSK с предмодуляционной гауссовской фильтрацией (GMSK) |

### 5.2. Процессоры модулирующего сигнала

#### QPSK

Для реализации QPSK процессор передаваемого сигнала в основной полосе частот содержит:

1. **Амплитудный корректор** с характеристикой $x/\sin x$, где $x = \pi T_s f$
2. **Передаточную функцию** вида корень квадратный из приподнятого косинуса ($\sqrt{RC}$)

Функция процессора, обозначенная выражением $\frac{x}{\sin x} \sqrt{RC}$, определяется формулой (4.2.19).

В приемнике такой фильтр используется в качестве согласованного фильтра Найквиста.

#### MSK и GMSK

Процессор модулирующего сигнала MSK включает интегратор и гауссовский ФНЧ. Для GMSK добавляется гауссовская предмодуляционная фильтрация.

#### FQPSK (QPSK Феера)

Простой, но эффективный фильтр основной полосы (сигнальный процессор), предложенный Обществом д-ра Феера (патенты США № 4,339,724 и 4,567,602). Этот процессор в случае QPSK формирует запатентованный Феером модулированный сигнал FQPSK.

**Преимущества FQPSK:**
- Удвоение емкости GSM-систем со стандартной GMSK
- Увеличение ресурса батареи
- Снижение внеполосного излучения в американской цифровой сотовой системе, использующей $\pi/4$-DQPSK

**Особенность формы сигнала:** процессор FQPSK формирует **только плавные переходы сигнала**; в отличие от него процессор MSK формирует резкие переходы и разрывы.

### 5.3. Спектральные плотности модулирующих сигналов

#### Спектральная плотность FQPSK

$$S(x) = T_s \left(\frac{\sin 2\pi x}{2\pi x}\right)^2 \frac{1}{1 - 4x^2}$$

где $x = fT_s$, а $T_s$ — длительность символа.

#### Спектральная плотность MSK

$$W'(f) = \frac{4h^2 T_s}{\pi^2} \cdot \frac{1 + \cos 2\pi f T_s}{(1 - 4f^2 T_s^2)^2}$$

где $h$ — постоянный коэффициент.

### 5.4. Практическая реализация

Модулирующие сигналы данной формы для MSK и FQPSK могут быть получены с помощью концептуальных схем формирования. Практически они могут быть реализованы путем:

- **Цифровой обработки сигналов (DSP)** — с помощью трансверсальных фильтров
- **Аналоговой обработки и фильтрации**

Экспериментально полученная глазковая диаграмма для скорости $f_b = 32$ кбит/с и соответствующий низкочастотный спектр модулирующего сигнала для FQPSK показывают **отсутствие межсимвольных искажений и дрожания** для сигнала с ограниченной полосой.

Глазковая диаграмма модулирующего сигнала для FQPSK-1 для скорости $f_b = 1$ Мбит/с (500 кБод), сформированная с помощью программируемой логической интегральной схемы Intel 740-FPGA, демонстрирует сигнал без межсимвольных искажений и дрожания, используемый в качестве модулирующего для квадратурных I- и Q-каналов модуляторов.

## 7. Заключение

Раздел 4.2 охватывает фундаментальные основы систем передачи в основной полосе частот:

1. **Двоичные системы** энергетически более эффективны, но спектрально менее эффективны, чем многоуровневые.
2. **Спектральная плотность** сигналов БВН имеет вид $(\sin x/x)^2$ с первым нулём на частоте следования символов.
3. **Идеальный канал Найквиста** с прямоугольной характеристикой и полосой $f_N = f_s/2$ обеспечивает передачу без МСИ благодаря нулевым переходам импульсной характеристики в моменты отсчета.
4. **Теорема о частичной симметрии** позволяет использовать реализуемые фильтры (приподнятый косинус) с сохранением условия отсутствия МСИ.
5. **Коэффициент скругления $\alpha$** определяет компромисс между спектральной эффективностью и дрожанием переходов.
6. **Современные стандарты** (QPSK, MSK, GMSK, FQPSK) используют описанные принципы для формирования сигналов с ограниченной полосой и высокой помехоустойчивостью.
